## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Notebook Library** | Organize all GoodNotes notebooks with subject and date tags |
| **Template Manager** | Track and organize custom GoodNotes templates by category |
| **Study Planner** | Plan study sessions with notebook and topic assignments |
| **Note Index** | Maintain a searchable index of key notes across all notebooks |
